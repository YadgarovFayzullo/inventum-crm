# INVENTUM CRM

CRM для учебного центра: ученики и родители, группы и переводы, посещаемость, оплаты и долги, лиды, преподаватели. Три роли: владелец, менеджер, преподаватель.

Стек: React 19, TypeScript, Vite, Tailwind CSS 4, Zustand. Данные пока хранятся в браузере (localStorage).

```bash
npm install
npm run dev      # разработка
npm run build    # production-сборка
```

UI-компоненты лежат в `src/ui/`, их список — на странице `/ui-kit` (доступна владельцу).
