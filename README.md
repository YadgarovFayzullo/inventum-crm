# INVENTUM CRM

CRM для учебного центра: ученики и родители, группы и переводы, посещаемость, оплаты и долги, лиды, преподаватели. Три роли — владелец, менеджер, преподаватель.

**Стек:** React 19 + TypeScript + Vite + Tailwind 4 (фронтенд) · Node 24 + Fastify (API) · PostgreSQL 17 · Cloudflare R2 (фото учеников) · Docker.

## Запуск в Docker (продакшен)

```bash
cp .env.example .env      # заполните POSTGRES_PASSWORD и, при желании, R2_*
docker compose up -d --build
```

Приложение: http://localhost:3001. Владелец создаётся при первом запуске: email из `OWNER_EMAIL`, пароль из `OWNER_PASSWORD` (если пусто — генерируется и один раз печатается в логе: `docker compose logs app`). Остальных пользователей владелец добавляет в **Настройки → Пользователи**.

Для публикации в интернете поставьте перед приложением HTTPS (Caddy, nginx или Cloudflare Tunnel) и задайте `COOKIE_SECURE=1`, `TRUST_PROXY=1`. База наружу не публикуется (порт 5432 привязан к 127.0.0.1).

## Разработка

```bash
docker compose up -d db   # только Postgres
npm install
npm run dev               # Vite на :5173 + API на :3001 (прокси /api)
```

Нужен `.env` (см. `.env.example`), в нём `DATABASE_URL`. Первые данные: **Настройки → Загрузить демо-данные**.

| Команда | Что делает |
|---|---|
| `npm run build` | сборка фронтенда (`dist/`) и сервера (`dist-server/`) |
| `npm start` | запуск собранного сервера |
| `npm run typecheck:server` | проверка типов сервера |
| `npm run test:server` | тесты API на реальном Postgres (`DATABASE_URL_TEST`, по умолчанию `127.0.0.1:5441`) |

Тесты чистят схему `public` в тестовой базе — не указывайте рабочую.

## Фото учеников (Cloudflare R2)

1. В R2 создайте **приватный** бакет.
2. R2 → *Manage API tokens* → токен с правом *Object Read & Write* на этот бакет.
3. Заполните `R2_ACCOUNT_ID`, `R2_ACCESS_KEY_ID`, `R2_SECRET_ACCESS_KEY`, `R2_BUCKET`.

Фото обрезается до квадрата и сжимается в браузере (≈30 КБ), на сервере проверяется содержимое файла (не только заголовок), а читает его только вошедший пользователь с нужными правами — публичных ссылок на фото нет. Без `R2_*` фото пишутся в папку `uploads` (подходит только для проб).

## Безопасность

- пароли — scrypt; сессия — случайный токен в httpOnly-cookie, в базе хранится только его хэш;
- 5 неудачных входов с одного IP на один email → блокировка на 15 минут;
- права проверяются на сервере (преподаватель получает только свои группы, без денег и лидов);
- защита от CSRF, CSP и другие заголовки безопасности, все входные данные проверяются схемами (zod), SQL — только с параметрами;
- смена пароля завершает все сессии пользователя.

## Что учесть

- При входе загружаются все данные центра целиком — быстро для сотен и тысяч учеников. Если центр вырастет до десятков тысяч записей посещаемости, понадобится подгрузка по периодам.
- Резервные копии базы: `docker compose exec db pg_dump -U inventum inventum > backup.sql`. Фото лежат в R2 и в этот дамп не входят.
